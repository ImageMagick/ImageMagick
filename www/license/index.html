quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg

License Summary in Simple Terms

Before diving into the legal text, here is a breakdown of what the ImageMagick license allows, forbids, and requires.

What it Allows
  • Freely download and use software for personal, internal, or commercial purposes.
  • Use software in packages or distributions you create.
  • Link against libraries under different licenses (and vice-versa).
  • Merge code into works under different licenses and extend patent grants.
What it Forbids
  • Redistribute any piece of ImageMagick-originated software without proper attribution.
  • Use ImageMagick Studio LLC marks to imply endorsement of your distribution.
  • Imply that you created the original ImageMagick software.
What it Requires
  • Include a copy of the license in any redistribution containing ImageMagick.
  • Provide clear attribution to ImageMagick Studio LLC.
Key Clarifications
  • Software is freely available without charge.
  • Compatible with the GPL v3.
  • Source code of modifications is not required to be redistributed.
  • Check export classification when exporting software.
