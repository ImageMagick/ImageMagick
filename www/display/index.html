Command-line Tools: Display

Use ImageMagick’s display program to showcase images or sequences on any X server. Explore example usages, terminal commands, and an interactive option summary.

Get ImageMagick Documentation
quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg
Example Usage Option Summary

Use the display program to display an image or image sequence on any X server. See Command Line Processing for advice on how to structure your display command or see below for example usages.

Example Usage

We list a few examples of the display command here to illustrate its usefulness and ease of use. To get started, let's display an image in the JPEG format:

display-jpeg.sh 
$ magick display rose.jpg

To tile a slate texture onto the root window, use:

display-root.sh 
$ magick display -size 1280x1024 -window root slate.png

To display a visual image directory of all your JPEG images, use:

display-vid.sh 
$ magick display 'vid:*.jpg'

The display program defaults to the X screen resolution. To display vector formats at their intended size, override the default resolution:

display-density.sh 
$ magick display -density 72 drawing.svg
You can find additional examples of using display in Examples of ImageMagick Usage.

-colors <value> preferred number of colors in the image
-colorspace <type> set image colorspace
-comment <string> annotate image with comment
-compress <type> image compression type

-crop <geometry> preferred size and location of the cropped image
-debug <events> display copious debugging information
-decipher <filename> convert cipher pixels to plain

-dispose <method> layer disposal method

-extract <geometry> extract area from image

-flatten flatten a sequence of images

-gravity <geometry> horizontal and vertical backdrop placement
