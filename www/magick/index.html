Command-line Tools: Magick

Powerful image manipulation with ImageMagick’s magick command-line tool. Convert, resize, crop, blur, sharpen, annotate, and transform images across formats with ease. Explore examples, options, and advanced features for professional-quality results.

Get ImageMagick Documentation
quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg

Use the magick program to convert between image formats, resize, blur, crop, despeckle, dither, draw on, flip, join, re-sample, and perform advanced image processing tasks.

CLI Processing Guide Jump to Option Summary
Basic Format Conversion

Convert an image from JPEG to PNG effortlessly.

convert.sh
$ magick rose.jpg rose.png
Resizing Images

Reduce the image dimensions before saving to PNG format.

resize.sh
$ magick rose.jpg -resize 50% rose.png
Complex Operations & Text Rendering

Combine drawing, channels, blurring, and colors into a single pipeline.

text-effects.sh
$ magick -size 320x85 canvas:none -font Bookman-DemiItalic -pointsize 72 \
  -draw "text 25,60 'Magick'" -channel RGBA -blur 0x6 -fill darkred -stroke magenta \
  -draw "text 20,55 'Magick'" fuzzy-magick.png
High-Quality Sigmoidal Resampling

Resize images with minimized artifacts using sigmoidal contrast and custom filters.

high-quality-resize.sh
$ magick input.png -colorspace RGB +sigmoidal-contrast 11.6933 \
  -define filter:filter=Sinc -define filter:window=Jinc -define filter:lobes=3 \
  -resize 400% -sigmoidal-contrast 11.6933 -colorspace sRGB output.png
Invoking Other Command-Line Tools

You can utilize other command-line tools through magick. Specify the sub-tool as the first argument or create a symbolic link to the binary—both approaches are equivalent.

symlink.sh
# Equivalent invocations:
$ ln -s magick identify
$ identify rose.jpg rose.png
$ magick identify rose.jpg rose.png
