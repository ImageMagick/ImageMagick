quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg

ImageMagick® is a free, open-source software suite for editing, processing, and converting digital images. It supports over 200 format variants, including modern standards like JPEG, PNG, GIF, TIFF, WebP, AVIF, and Ultra HDR.

High Performance Multi-threaded, OpenCL & parallel processing.
CLI & Automation Scripting-first design for mass batch jobs.
Extensive APIs Bindings for C, C++, Python, .NET, Node.js.

Features & Capabilities

Discover what ImageMagick can do for your workflows.

Animation Format

Create GIF or WebP animated sequences from image frames.

Bilateral Blur Filter

Edge-preserving, noise-reducing non-linear smoothing filter.

Color Management Color

Accurate profile processing with built-in gamma compression and expansion.

Command-Line Processing Core

Automate and script complex multi-step operations efficiently from terminal interfaces.

Convex Hull Vision

Calculate smallest area bounding polygons, unrotate angles, and geometry metadata.

Format Conversion Core

Convert rapidly between 200+ standard formats (PNG, JPEG, WebP, AVIF, HEIC, TIFF).

High Dynamic-Range (HDR) Rendering

Represent wide ranges of intensity levels across extreme light and shadow contrast.

Tera-Pixel Support Performance

Seamlessly read, process, and write giga-pixel or tera-pixel sized datasets.
