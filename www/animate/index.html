Command-line Tools: Animate

Animate an image sequence on any X server with ImageMagick command line tools.

Get ImageMagick Documentation
quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg
Example Usage Option Summary

Use the animate program to animate an image sequence on any X server. See Command Line Processing for advice on how to structure your animate command, or check below for usage examples.

Example Usage

Below are common examples illustrating how to use the animate command. To get started, animate an image sequence in GIF format:

animate-gif.sh 
$ magick animate movie.gif

To animate an entire directory of JPEG images, pass a wildcard pattern:

animate-folder.sh 
$ magick animate *.jpg
Looking for advanced parameters? You can find additional examples in the ImageMagick Usage Documentation.

-colormap <type> Shared or Private

-colorspace <type> set image colorspace

-compress <type> image compression type

-crop <geometry> preferred size and location of the cropped image
-debug <events> animate copious debugging information
-decipher <filename> convert cipher pixels to plain

-delay <centiseconds> animate the next image after pausing
-density <geometry> horizontal and vertical density of the image

-display <server> get image or font from this X server

-edge <radius> apply a filter to detect edges in the image

-extract <geometry> extract area from image
-filter <type> use this filter when resizing an image
-flatten flatten a sequence of images
-flip flip image in the vertical direction
-flop flop image in the horizontal direction
-frame <geometry> surround image with an ornamental border
-gamma <value> level of gamma correction
-geometry <geometry> preferred size or location of the image

-log <format> format of debugging information
-map <filename> transform image colors to match this set of colors

-sharpen <geometry> sharpen the image

-thumbnail <geometry> create a thumbnail of the image
