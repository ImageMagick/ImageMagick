Color Names

Discover ImageMagick’s comprehensive list of color names and specifications. Learn how to define colors using names, RGB, RGBA, HSL, HSB, CMYK, Lab, and ICC models, with examples and conversion tools for precise image editing.

Get ImageMagick Documentation
quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg

A wide range of ImageMagick options and methods accept colors as arguments. Colors can be defined via standard names, decimal/hexadecimal RGB/RGBA triplets, or advanced models like HSL, HSB, CMYK, Lab, and ICC.

Example Usage

Each of the following commands produces the same lime border around the image. (Use double quotes for Windows.)

$ magick -bordercolor lime -border 10 image.jpg image.png
$ magick -bordercolor '#0f0' -border 10 image.jpg image.png
$ magick -bordercolor '#00ff00' -border 10 image.jpg image.png
$ magick -bordercolor 'rgb(0,255,0)' -border 10 image.jpg image.png
$ magick -bordercolor 'rgb(0,100%,0)' -border 10 image.jpg image.png

Recognized color names include common choices like aqua, black, blue, fuchsia, gray, green, lime, maroon, navy, olive, purple, red, silver, teal, white, yellow, and many more detailed in the table below.

Color Model Specification

Numerical color specifications support sRGB, CMYK, HSL, and HSB models. For example, all of the following specify the exact same shade of red in sRGB:

#f00                       4-bit  #rgb
#ff0000                    8-bit  #rrggbb
#ff0000ff                  8-bit  #rrggbbaa
#fff000000                12-bit  #rrrgggbbb
#ffff00000000             16-bit  #rrrrggggbbbb
#ffff00000000ffff         16-bit  #rrrrggggbbbbaaaa
#ffffffff0000000000000000ffffffff
                          32-bit  #rrrrrrrrggggggggbbbbbbbbaaaaaaaa
rgb(255, 0, 0)            an integer in the range 0—255 for each component
rgb(100.0%, 0.0%, 0.0%)   a float in the range 0—100% for each component

Hexadecimal Notation

Hex values start with # followed by 3 to 32 characters. Three-digit notation (#rgb) expands by doubling digits (e.g., #fb0 becomes #ffbb00). Tip: Use hexadecimal notation for optimal performance since ImageMagick can parse them directly without loading the expansive color lookup table.

Functional Notation & Alpha

Functional colors use syntax like rgb(r, g, b) or percentages. As of ImageMagick 7.0.10-53, commas are optional, and alpha transparency can be specified using a slash separator (e.g., rgb(255 128 0 / 50%)). Use none as a quick shorthand for fully transparent black (rgba(0, 0, 0, 0.0)).

Grayscale Values

Non-linear gray values can be defined via names, single intensities, or alpha variants:

gray50            near mid gray
gray(127)         near mid gray
gray(50%)         mid gray
graya(50%, 0.5)   semi-transparent mid gray

For linear gray values, chain with -colorspace RGB -colorspace Gray or use -colorspace LinearGray (available in ImageMagick 6.9.9-29 and 7.0.7-17+).

HSL and HSB Color Models

ImageMagick supports hue-saturation-lightness (HSL) and hue-saturation-brightness (HSB) models as intuitive alternatives to sRGB. Hue represents a color angle from 0 to 360 degrees (red=0/360, green=120, blue=240), while saturation, brightness, and lightness are specified as values from 0—255 or percentages (0—100%).

HSB Examples (Cone Model)

hsb(0,   100%,  100%)    full red
hsb(120, 100%,  100%)    full green
hsb(120, 100%,  50%)     dark green
hsb(120, 50%,   50%)     pastel green

HSL Examples (Double-Cone Model)

hsl(0,   100%,  50%)     full red
hsl(120, 100%,  100%)    white
hsl(120, 100%,  50%)     full green
hsl(120, 50%,   50%)     medium green

Advanced Color Spaces: Lab, ICC, and Device Colors

Specify CIE Lab colors directly or examine their internal quantum bias using the text format handler:

cielab(62.253188, 23.950124, 48.410653)
$ magick xc:cyan -colorspace LAB txt:
# ImageMagick pixel enumeration: 1,1,65535,cielab
0,0: (59711,20409.5,-3632.9)  #E93F4FBA71CF  cielab(91.1132,-48.0855,-14.1358)

$ magick -size 100x100 xc:"cielab(91.1132,-48.0855,-14.1358)" -colorspace sRGB cyan.png

You can also specify generic colors via the icc-color keyword or uncalibrated device values:

icc-color(cmyk, 0.11, 0.48, 0.83, 0.00)  cmyk
icc-color(srgb, 1, 0, 0)                  non-linear rgb
icc-color(lineargray, 0.5)               linear gray

device-gray(0.5)
device-rgb(0.5, 1.0, 0.0)
device-cmyk(0.11, 0.48, 0.83, 0.00)

ImageMagick also natively supports wide-gamut color spaces such as Lab, LCH, and Display-P3.
