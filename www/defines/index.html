Defines

Maximize image processing with the -define command-line option, tailor coders/decoders, and control operations with precision for optimal results.

Get ImageMagick Documentation
quickstart.sh
# Install via your favorite Package Manager
$ brew install imagemagick
# Convert PNG to WebP with compression
$ magick input.png -quality 85 output.webp
# Resize image maintaining aspect ratio
$ magick input.jpg -resize 800x600^ output.jpg

The -define command-line option adds specific global settings generally used to control coders and image processing operations.

About Definitions

This option creates one or more definitions for coders and decoders while reading and writing image data. Definitions control file format coder modules and image processing operations beyond normal options.

Defined settings appear in -verbose information ("info:" output format) as Artifacts.

Usage & Management
  • Missing values create empty-valued flags (on/off control).
  • Use -define keys to remove previous definitions.
  • Use +define "*" to clear all existing definitions.
  • Equivalent settings can use -set "option:key" "value" with Format Properties.
example-define.sh
$ magick bilevel.tif -define ps:imagemask eps3:stencil.ps
$ magick arrow.tga -set colorspace:auto-grayscale=off myArrow.tga
registry-define.sh
# Set temporary work path in registry
$ magick -define registry:temporary-path=/data/tmp input.png output.png

Recognized Defines

Reference

The options and keys are case-independent (converted to lowercase for decoders) while values are case-dependent. Here is the complete list of recognized defines:

connected-components:verbose=true Lists id, bounding box, centroid, area, mean color for each region.
